Términos de Servicio

Dabot - Bot de Discord

Última actualización: 23 de agosto de 2026

1. Aceptación de los Términos

Al invitar, acceder o utilizar Dabot (en adelante, "el Bot") en tu servidor de Discord, aceptas estar sujeto a estos Términos de Servicio. Si no estás de acuerdo con alguna parte de estos términos, no debes utilizar el Bot.

2. Descripción del Servicio

Dabot es un bot multipropósito para Discord con moderación, entretenimiento, utilidades, tickets, niveles, economía virtual y dashboard web en dabot.davito.es. El servicio se proporciona "tal cual" y puede ser modificado, actualizado o discontinuado en cualquier momento.

3. Uso Aceptable

Al utilizar Dabot, te comprometes a:

  • No utilizar el Bot para actividades ilegales, fraudulentas o no autorizadas
  • No intentar hackear, modificar o realizar ingeniería inversa del Bot
  • No utilizar el Bot para acosar, abusar o dañar a otros usuarios
  • No sobrecargar intencionalmente el Bot con solicitudes excesivas (spam)
  • Cumplir con los Términos de Servicio y Directrices de la Comunidad de Discord
  • No utilizar el Bot para distribuir malware, virus o contenido malicioso
  • No intentar eludir las medidas de seguridad o restricciones del Bot

Prohibiciones Importantes

El uso del Bot para actividades que violen las leyes locales, nacionales o internacionales resultará en la suspensión inmediata del servicio y puede ser reportado a las autoridades competentes.

4. Permisos y Acceso

Para funcionar correctamente, Dabot requiere permisos que dependen de los módulos que active cada servidor. El administrador debe conceder solo los permisos necesarios y puede gestionar la configuración desde dabot.davito.es.

  • Leer y enviar mensajes
  • Gestionar mensajes y canales
  • Gestionar roles y miembros
  • Conectarse y hablar en canales de voz
  • Ver registros de auditoría

Es responsabilidad del administrador del servidor otorgar únicamente los permisos necesarios para las funcionalidades deseadas.

5. Recopilación y Uso de Datos

El Bot puede recopilar y almacenar ciertos datos necesarios para su funcionamiento. Para más información sobre qué datos se recopilan y cómo se utilizan, consulta nuestra Política de Privacidad.

6. Disponibilidad del Servicio

Aunque nos esforzamos por mantener el Bot operativo 24/7, no garantizamos que el servicio esté disponible de forma ininterrumpida. El Bot puede experimentar:

  • Tiempo de inactividad por mantenimiento programado o no programado
  • Interrupciones debido a problemas técnicos
  • Limitaciones de funcionalidad debido a cambios en la API de Discord
  • Suspensión temporal o permanente sin previo aviso

Actualizaciones y Cambios

Nos reservamos el derecho de modificar, actualizar o discontinuar cualquier funcionalidad del Bot en cualquier momento. Los cambios importantes serán comunicados a través de nuestro servidor de Discord oficial.
