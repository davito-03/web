Qué es

DavoGram es el bot de Telegram (menús, premium, juegos, alertas de precio con yfinance). El userbot es otra pieza: escucha solo Mensajes Guardados, descarga el archivo y lo sube a la librería de Jellyfin en Drive. No pasa por el límite de 20 MB del Bot API.

DavoGram is the Telegram bot (menus, premium, games, price alerts). The userbot is separate: it watches Saved Messages only, downloads the file and uploads it to the Jellyfin Drive library — bypassing the Bot API 20 MB cap.

Funciones clave: handle_saved_messages_media, process_queue_item, _upload_to_drive (rclone y, si falla, API resumable). Panel de progreso en el propio chat (/panel). La cola sobrevive un reinicio.

El userbot pide un nombre de archivo antes de subir. No reencoda: el punto era conservar la calidad original para cine.

Key functions: media handler, queue worker, rclone-first upload with Drive API fallback. Progress lives in-chat. The queue survives a restart. Files are not transcoded — original quality for movies.

Lo que no se publica

Sesión Pyrogram (*.session), credentials.json, gdrive_credentials.json, token.json, cookies, SQLite. En GitHub, config.py y el userbot leen os.environ. En el VPS las claves siguen en disco; el repo público no las lleva.

Pyrogram session, Google credential files, cookies and SQLite stay off git. The public tree reads environment variables only.
