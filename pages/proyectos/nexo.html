Qué es

Nexo es un servidor de Discord (voz activa, social, gaming, anime, gatos). El bot cubre lo que un bot genérico no cubre bien: VoiceMaster, economía nexocoin, misiones semanales, RPG, mascotas, counting, bumps de DISBOARD y tickets con un asistente (Neko) que recuerda el hilo.

La restricción a un guild no es un “todo”. Es un producto cerrado: slash commands se despliegan solo ahí (src/index.ts) y GuildCreate en otro ID llama a guild.leave().

Custom bot for the Nexo Discord: VoiceMaster, nexocoin economy, weekly missions, RPG, pets, counting, DISBOARD bumps, and tickets with a support AI (Neko) that remembers the thread.

Single-tenant on purpose: slash commands deploy only to that guild; joining any other server triggers guild.leave().

Un contenedor. TypeScript se compila a dist/ (Dockerfile multi-stage). Los slash viven en src/commands/ agrupados por área; la lógica gorda está en src/modules/. Los events de discord.js son finos: delegan en los motores (XP, automod, VoiceMaster, invites…).

Al apagar (SIGTERM) se reembolsan mesas de casino abiertas (economy/tables.ts) y se destruye el cliente con gracia de 25 s en Compose.

One container. TypeScript compiles to dist/. Slash commands live under src/commands/; heavy logic is in src/modules/. Discord events stay thin and call those engines.

On SIGTERM, open casino tables are refunded before the client is destroyed.

Módulos

Moderación

moderation/actions.ts casos warn/kick/ban/timeout/softban, DM con botón de apelación. Masivos hasta 15 objetivos.

AutoMod

Spam por ventana, invites, enlaces, caps, bad words. Hits en tabla automod_hits.

VoiceMaster

Hub ➕ crear sala. Panel: lock, hide, rename, límite, claim, transfer, kick. Tabla temp_voices.

Niveles

XP chat + minutos en VC (×1.5 boosters), role rewards, tarjeta Canvas al subir.

Tickets

Categorías, claim, cierre, transcripciones HTML. Neko responde hasta que staff reclama el ticket.

Backup

ZIP con roles, canales, emojis, bans, casos, niveles, tickets y mensajes. Restore con mapeo de IDs.

Economía

nexocoin: work/daily/crime, tienda, P2P, subastas, trading, minería, propiedades, préstamos, impuestos semanales.

Misiones / RPG / pets

Tablón semanal de 7 misiones. RPG con clanes y mazmorras. Mascotas con hambre/felicidad y expediciones.

Comunidad

Cumpleaños (zona Madrid), matrimonios, encuestas, frase del día + gatito, counting, bumps DISBOARD, invites.

Logs

Deletes, edits, voz, audit log, canales y roles, enrutados a canales por tipo.

Welcome / boosts

Tarjetas Canvas (welcome, level-up, boost). Tracker de Server Boosts para sorteos ponderados.

Giveaways

Requisitos de rol, nivel o booster. Entradas extra por boosts e invites.

IA de soporte (Neko)

modules/ai/client.ts arma una cola de intentos y se queda con el primero que responde. Si un proveedor da 429, lo enfría (cooldown) y sigue. Orden:

local (Ollama) → Groq → Gemini (varias claves) → OpenRouter → Cohere → Cloudflare Workers AI → OpenAI.

La memoria del ticket (ai/memory.ts) guarda un resumen y hechos en SQLite para no reenviar todo el hilo. El prompt de normas se carga con /ticket ia prompt:.

modules/ai/client.ts builds a failover queue; 429 cools that provider. Order: local Ollama → Groq → Gemini (multi-key) → OpenRouter → Cohere → Cloudflare → OpenAI.

Ticket memory stores a summary plus facts so the whole thread is not resent. Staff can set the policy prompt with /ticket ia prompt:.

Sitios del código que importan

Eventos delgados, motores gordos. messageCreate.ts no es un switch de mil líneas: llama a automod, XP, counting, bump y chatbot. Eso se deja testear y no se mezcla con los slash.

Thin events, fat engines. messageCreate.ts delegates to automod, XP, counting, bump and chatbot instead of a thousand-line switch.

Schema explícito. database/schema.ts declara decenas de tablas (casos, tickets, economía, RPG, pets, misiones, counting…). WAL y foreign keys. No es un JSON suelto.

Explicit schema. database/schema.ts is a real relational model (cases, tickets, economy, RPG, missions…) with WAL and foreign keys.

Canvas de marca. Welcome, level-up y boost usan las PNG de assets/images/ y fuentes Inter. El logo de esta ficha es media/nexo.png.

Branded canvas cards for welcome, level-up and boosts. This page uses media/nexo.png.

Operación

Un compose: docker compose up -d --build. Datos en ./data, backups en ./backups. Token y claves de IA en .env (Zod al cargar). El repo público no lleva la base ni los ZIP de restore.

Single compose service. Data and backups on host volumes. Token and AI keys in .env (Zod). Public repo has neither the database nor restore ZIPs.
